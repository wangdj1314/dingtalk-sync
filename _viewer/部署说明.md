# 钉钉聊天记录浏览 — 使用与部署说明

一个纯静态网页，直接读取本同步目录下的 `_all_convs.json`、`_chat_export/*.csv`
以及各会话文件夹里的文件，用聊天窗口的形式浏览钉钉聊天记录。

- 无需数据库、无需后端、无外部 CDN 依赖（内网/离线可用）
- 数据更新（每天同步）后网页自动反映，无需重新打包
- 已下载的文件可直接点击打开/下载

## 目录结构

```
钉钉同步/                     ← 作为"文档根目录"
├── _all_convs.json          会话列表（网页读取）
├── _chat_export/*.csv       聊天记录（网页读取）
├── <会话名>/<日期>/<文件>   已下载的文件（网页链接）
└── _viewer/                 ← 本网页
    ├── index.html
    ├── styles.css
    ├── app.js
    ├── build_index.py       生成 files_index.json 的脚本
    ├── files_index.json     已下载文件索引（标注"已下载/大小"）
    └── 部署说明.md
```

> 关键点：网页在 `_viewer/` 里，数据在它的**上一级**目录。
> 因此"文档根目录"必须指向 **`钉钉同步`** 这个文件夹（不是 `_viewer`），
> 通过 `/_viewer/` 访问网页。

## 一、本地预览（开发机）

在 `钉钉同步` 目录下起一个静态服务器即可（任选其一）：

```bash
# 用 Python（推荐）
cd /path/to/钉钉同步
python -m http.server 8777
# 浏览器打开 http://127.0.0.1:8777/_viewer/
```

> 注意：必须通过 http 访问，不能直接双击 `index.html`（file:// 协议下浏览器
> 会因安全限制无法读取 CSV/JSON）。

## 二、部署到群晖（Web Station）

群晖上已有本文件夹的备份，直接把它作为网站根目录发布即可。

1. **套件中心** 安装 **Web Station**（及其依赖的 Nginx/Apache，二选一，默认即可）。
2. 打开 **Web Station → 网页服务门户（或"虚拟主机"）→ 新增**：
   - 门户类型：选择 **基于名称** 或 **基于端口**（比如端口 `8080`）。
   - **文档根目录**：指向本同步文件夹，例如
     `/volume1/<你的共享文件夹>/钉钉同步`
   - HTTP 后端服务器：Nginx（默认）即可。
3. 保存后，通过浏览器访问：
   ```
   http://<群晖IP>:<端口>/_viewer/
   ```
   例如 `http://192.168.1.10:8080/_viewer/`

### 让 `/_viewer/` 成为默认首页（可选）

如果想直接用 `http://<群晖IP>:<端口>/` 打开，可在 Web Station 的门户设置里
把默认首页/重定向指向 `/_viewer/index.html`；或在文档根目录放一个跳转用的
`index.html`（内容仅一行）：

```html
<meta http-equiv="refresh" content="0; url=_viewer/index.html">
```

### 关于中文文件名

Nginx/Apache 默认支持 UTF-8 路径，中文会话名、中文文件名均可正常访问。
若个别文件打不开，检查 Web Station 的字符集设置为 UTF-8 即可。

## 三、数据更新后

- **聊天记录 / 新会话**：每天同步脚本更新 `_chat_export/*.csv` 与
  `_all_convs.json` 后，刷新网页即可看到最新内容，**无需任何额外操作**。
- **已下载文件的"已下载"标记与大小**：由 `files_index.json` 提供。
  新同步下载了文件后，重新生成一次索引即可：
  ```bash
  cd _viewer
  python build_index.py
  ```
  即使不重新生成，文件依然可以点击打开（网页会按 `会话/日期/文件名` 规则
  直接尝试打开），只是不会显示"已下载 + 文件大小"的绿色标记。
  > 建议：把这行加进每天的同步任务里，索引就能一直保持最新。

## 四、自定义

- **谁算"我"（消息靠右显示）**：编辑 `app.js` 顶部的
  `const SELF_NAMES = ["汪德嘉", "DJ Wang"];`，按需增删名字。
- **每批加载条数**：`app.js` 顶部的 `const BATCH = 300;`。

## 五、功能说明

- 左侧：会话列表，可按名称搜索，可按"全部 / 群聊 / 单聊"筛选。
- 右侧：聊天窗口，气泡样式，本人消息靠右（绿色），他人靠左（白色）。
- 消息：
  - **文字**：保留钉钉的颜色、@提醒、加粗、分隔线等基本格式。
  - **文件**：卡片形式，绿色"已下载"可直接打开；灰色"未下载/已过期"是钉钉
    链接过期未能下载的文件（钉钉平台限制），点击会尝试打开但可能 404。
  - **图片**：钉钉未随文件下载图片，显示为"🖼️ 图片"占位，夹带的文字正常显示。
  - **日程**：显示为"📅 日程消息"。
- 按天显示日期分隔条；每条消息显示时间。
- 消息按时间升序排列，并自动去除增量导出产生的重复行。
- 大会话默认加载最近 300 条，可点顶部"加载更早的消息"逐批查看。

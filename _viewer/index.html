⚠️ 请通过 HTTP 服务打开本页面

你当前是直接用浏览器打开 index.html（file:// 协议），浏览器会禁止网页读取本地聊天记录文件，所以左侧会话列表为空。

请在工作目录启动一个临时本地服务：

cd "E:\myfile\钉钉同步"
python -m http.server 8777 --bind 127.0.0.1

然后在浏览器访问：

http://127.0.0.1:8777/_viewer/

部署到群晖后，通过 Web Station 的 HTTP 地址访问即可，不会出现此提示。
